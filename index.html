↑ Optional: upload labeling to GitHub

Destination: utkauraslab/TalktoSim-DataLabeling · Public repository

Uploads contain labels, Class, custom fields, source video filename, annotator and timestamps. Anyone can view uploaded data. The source video is never uploaded.

Labels-only is the default. Each uploaded file must be 50 MB or smaller; larger ZIPs can be downloaded locally.

Used only for this upload; never saved in browser storage or in the repository. Your GitHub account must have write access to this repository.

How to authorize this upload
  1. Create a fine-grained GitHub token.
  2. Choose resource owner utkauraslab, select Only select repositories → TalktoSim-DataLabeling, and allow Contents: read and write. Organization approval may be required.
  3. Copy the token into the field above. No token is needed for local downloads.

Not authorized. Your data stays on this browser; local downloads remain available.
